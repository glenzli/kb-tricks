# Agent Instructions

This repository is `dev-skeleton`, not the older `dev-cycle` or `kb-tricks` system.

Before changing this repository:

1. Read `DEV_SKELETON.md`.
2. Read `REVIEW_SKELETON.md`.
3. Treat those files as orientation, not authority.
4. Verify factual claims against the repository files you are editing.

Do not recreate the old Context/KB CLI flow. Do not add long-lived code summaries, module maps, class maps, or test/onboarding workflows unless the project direction explicitly changes.

When editing skills, keep `SKILL.md` concise and trigger descriptions precise. When editing templates, keep them stable and project-agnostic.
